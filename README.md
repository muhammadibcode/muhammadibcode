## How I work

- **Constrain the model, then measure it.** In Shroomy every AI-generated exercise must fit one of six fixed interaction formats, enforced in the tool schema. That is what made a generative product renderable, testable and comparable.
- **Ship the measurement with the feature.** Per-exercise ratings, funnel steps, generation latency and safety decisions are instrumented from day one, and the numbers decide what stays.
- **Treat prompts and evals as product specs.** Scout's match reasoning only ships when it passes rule checks, a calibrated LLM judge and sampled human review on the same fixed test set.
- **Make the hard trade-offs explicit.** Streaming versus caching for voice, deterministic templates versus LLM copy for notifications, which model tier earns its cost on which call. The Shroomy case study lists the decisions and the evidence behind them.

**Stack I am comfortable in:** Flutter and Dart, TypeScript and Next.js, Supabase and Postgres, Firebase, the Anthropic, OpenAI and ElevenLabs APIs, PostHog, RevenueCat. I use coding agents heavily and deliberately, against written specifications.
